Чтобы изолировать фоновый процесс на определенной странице и не дать ему мешать вашей обычной работе, вам нужно полностью разделить сессии браузера.
Вот 3 лучших способа сделать это, отсортированных по надежности:
1. Используйте режим инкогнито (Самый быстрый способ)
Этот способ создает изолированную сессию с отдельными файлами cookie. Фоновый скрипт не будет пересекаться с вашими основными вкладками.
Нажмите комбинацию клавиш Ctrl + Shift + N (в Windows) или Cmd + Shift + N (в Mac).
В открывшемся темном окне вставьте ссылку на нужный сайт.
Вынесите это окно на отдельный монитор или сверните.
2. Создайте новый профиль пользователя (Самый надежный способ)
Идеально, если скрипту нужно сохранять авторизацию (логин/пароль) или историю, не смешивая их с вашими личными данными. Каждое окно профиля работает как абсолютно независимый браузер.
Кликните на иконку вашего профиля (круглый аватар в правом верхнем углу Chrome).
Внизу выпадающего меню нажмите кнопку «Добавить» (Add).
Выберите «Продолжить без входа в аккаунт» (чтобы не привязывать почту).
Введите любое имя (например, «Скрипт») и нажмите «Готово».
В открывшемся новом окне запустите вашу программу.
3. Запуск отдельного процесса через ярлык (Для продвинутых)
Если программа все равно тормозит основное окно, можно принудительно запустить Chrome как совершенно другой системный процесс с отдельной папкой данных.
Создайте копию ярлыка Google Chrome на рабочем столе.
Кликните по ней правой кнопкой мыши и выберите «Свойства».
В поле «Объект» в самый анонец (через пробел после кавычек) добавьте: --user-data-dir="C:\ChromeProfile"

Вот три главных правила дореформенной грамматики, объясняющие такое написание:
Буква «і» («и десятеричное»): В слове знаніе буква і пишется на месте привычной «и», потому что сразу за ней следует гласная буква «е». В дореволюционном русском языке существовало четкое правило: перед гласными (и перед буквой «й») всегда ставилась і.

python
import os
import shutil
from github import Github
TOKEN = "СЮДА_ВСТАВЬТЕ_ВАШ_НОВЫЙ_ТОКЕН_GHP"
REPO_NAME = "yanleonov/ai-library-nauka2050"
def auto_upload_txt_files():
# Защита от бесконечного зависания консоли
g = Github(TOKEN, timeout=10)
try:
repo = g.get_repo(REPO_NAME)
except Exception as e:
print(f"Ошибка авторизации на GitHub! Проверьте токен. Детали: {e}")
return
# Ищем все файлы .txt в папке на компьютере
files_in_folder = [f for f in os.listdir('.') if f.endswith('.txt')]
if not files_in_folder:
print("В папке нет новых .txt файлов для отправки!")
return
print(f"Найдено новых текстовых файлов на ПК: {len(files_in_folder)}")
# 1. Загружаем или обновляем сами файлы книг в папке books на GitHub
for filename in files_in_folder:
with open(filename, "r", encoding="utf-8") as file:
content = file.read()
path_in_repo = f"books/{filename}"
try:
contents = repo.get_contents(path_in_repo)
repo.update_file(contents.path, f"Авто-обновление книги: {filename}", content, contents.sha)
print(f" ✓ Файл проверен/обновлен на GitHub: {filename}")
except Exception:
repo.create_file(path_in_repo, f"Авто-добавление книги: {filename}", content)
print(f" ✓ Загружен новый файл на GitHub: {filename}")
# 2. Умное добавление новых ссылок в index.html без удаления старых
print("\nАнализ главной страницы сайта...")
try:
index_file = repo.get_contents("index.html")
index_html = index_file.decoded_content.decode("utf-8")
except Exception as e:
print(f"Ошибка: не удалось скачать index.html с GitHub: {e}")
return
is_changed = False
for filename in files_in_folder:
link_url = f"books/{filename}"
# Если такой ссылки ещё нет на сайте, аккуратно добавляем её в список <ul>
if link_url not in index_html:
clean_name = filename.replace(".txt", "")
new_link_code = f'<li><a href="{link_url}">{clean_name}</a></li>'
# Встраиваем новую строку сразу после открытия тега <ul>
index_html = index_html.replace("<ul>", f"<ul>\n        {new_link_code}")
is_changed = True
print(f" + Ссылка на '{clean_name}' добавлена в код сайта.")
# Если появились новые ссылки, обновляем index.html на сервере
if is_changed:
try:
repo.update_file("index.html", "Добавление новых ссылок без удаления старых", index_html, index_file.sha)
print(" ✓ Главная страница сайта index.html успешно дополнена!")
except Exception as e:
print(f" Ошибка при отправке index.html на GitHub: {e}")
else:
print(" Все ссылки на сайте уже актуальны.")
# 3. АВТОПЕРЕНОС: убираем отправленные файлы в локальный архив на ПК
print("\nПеренос отправленных файлов в архив...")
archive_folder = "Отправленные_книги"
# Создаем папку для архива на компьютере, если её ещё нет
if not os.path.exists(archive_folder):
os.makedirs(archive_folder)
for filename in files_in_folder:
try:
# Перемещаем файл с ПК в папку архива
shutil.move(filename, os.path.join(archive_folder, filename))
print(f" -> Файл убран в архив на ПК: {filename}")
except Exception as e:
print(f" Не удалось переместить файл {filename} в архив: {e}")
if __name__ == "__main__":
auto_upload_txt_files()

65001 — это специальный цифровой код кодировки UTF-8 в операционной системе Windows [image_aQ4lPW.png].
По умолчанию командная строка Windows (CMD) в нашей стране использует старую кодировку DOS (она называется CP866) [image_aQ4lPW.png]. В этой старой кодировке компьютер видит русские буквы совсем не так, как современный Python [image_aQ4lPW.png].
Когда вы запускаете скрипт, и Windows видит в пути папки русские слова «ИИПРО» или «Всякие Проги», в старой кодировке они превращаются в нечитаемые «кракозябры» (ошибки вроде ╧Ёр┘х ╧Ёюуш) [image_aQ4lPW.png]. Из-за этого Python спотыкается и не может найти файл uploader.py [image_aQ4lPW.png].
Команда chcp 65001 (расшифровывается как Change Code Page 65001) принудительно переключает язык командной строки на универсальный международный стандарт UTF-8 [image_aQ4lPW.png]. После этого Windows начинает идеально «видеть» и понимать любые русские буквы, пробелы и символы в названиях ваших папок и файлов [image_aQ4lPW.png].

def auto_upload_txt_files():
g = Github(TOKEN)
repo = g.get_repo(REPO_NAME)
# Ищем все файлы .txt в папке на компьютере
files_in_folder = [f for f in os.listdir('.') if f.endswith('.txt')]
if not files_in_folder:
print("В папке нет новых .txt файлов для отправки!")
return
print(f"Найдено новых текстовых файлов на ПК: {len(files_in_folder)}")
# Текст мусорной плашки для удаления
garbage_text = (
"Чтобы проанализировать отзыв и улучшить работу сервисов, мы можем использовать "
"сведения из вашего аккаунта и данные о вашей системе в соответствии с Политикой "
"конфиденциальности и Условиями использования. Если вы обнаружили материалы, "
"нарушающие закон, запросите их удаление."
)
# 1. Загружаем или обновляем сами файлы книг в папке books на GitHub
for filename in files_in_folder:
with open(filename, "r", encoding="utf-8") as file:
content = file.read()
# Автоматически вырезаем мусор от лайков из текста, если он там есть
if garbage_text in content:
content = content.replace(garbage_text, "")
print(f" ✂ Из файла {filename} автоматически удален текст отзыва Google.")
path_in_repo = f"books/{filename}"
try:
contents = repo.get_contents(path_in_repo)
repo.update_file(contents.path, f"Авто-обновление книги: {filename}", content, contents.sha)
print(f" ✓ Файл проверен/обновлен на GitHub: {filename}")
except Exception:
repo.create_file(path_in_repo, f"Авто-добавление книги: {filename}", content)
print(f" ✓ Загружен новый файл на GitHub: {filename}")
# 2. Умное добавление новых ссылок в index.html без удаления старых
print("\nАнализ главной страницы сайта...")
try:
index_file = repo.get_contents("index.html")
index_html = index_file.decoded_content.decode("utf-8")
except Exception as e:
print(f"Ошибка: не удалось скачать index.html с GitHub: {e}")
return
is_changed = False
for filename in files_in_folder:
link_url = f"books/{filename}"
# Если такой ссылки ещё нет на сайте, аккуратно добавляем её в список <ul>
if link_url not in index_html:
clean_name = filename.replace(".txt", "")
new_link_code = f'<li><a href="{link_url}">{clean_name}</a></li>'
# Встраиваем новую строку сразу после открытия тега <ul>
index_html = index_html.replace("<ul>", f"<ul>\n        {new_link_code}")
is_changed = True
print(f" + Ссылка на '{clean_name}' добавлена в код сайта.")
# Если появились новые ссылки, обновляем index.html на сервере
if is_changed:
try:
repo.update_file("index.html", "Добавление новых ссылок без удаления старых", index_html, index_file.sha)
print(" ✓ Главная страница сайта index.html успешно дополнена!")
except Exception as e:
print(f" Ошибка при отправке index.html на GitHub: {e}")
else:
print(" Все ссылки на сайте уже актуальны.")
# 3. АВТОПЕРЕНОС: убираем отправленные файлы в локальный архив на ПК
print("\nПеренос отправленных файлов в архив...")
archive_folder = "Отправленные_книги"
# Создаем папку для архива на компьютере, если её ещё нет
if not os.path.exists(archive_folder):
os.makedirs(archive_folder)
for filename in files_in_folder:
try:
# Перемещаем файл с ПК в папку архива
shutil.move(filename, os.path.join(archive_folder, filename))
print(f" -> Файл убран в архив на ПК: {filename}")
except Exception as e:
print(f" Не удалось переместить файл {filename} в архив: {e}")
